# 共用业务逻辑边界

本目录位于小程序内部，以保持直接打开微信开发者工具即可编译的使用方式。其中以下模块同时被 Web（`web/src`，用于本地和云端 Web）引用，并非小程序专属实现：

- `types.ts`：岩壁、岩点、线路及坐标等数据类型。
- `transform.ts`：坐标转换、拖动边界限制与缩放。
- `geometry.ts`：圆形、多边形命中检测与最近岩点查找。
- `editor.ts`：线路岩点角色编辑、撤销与序列化。

修改这些共用模块时：

- 保持类型与纯业务计算独立，不引入微信 API、浏览器 DOM、网络请求或具体存储依赖；平台相关逻辑放在各端调用方。
- 调整导出、字段或行为前检查两端调用，并验证 Web 与小程序的相关功能；不要仅按小程序内部代码处理。
- 目前继续在此维护唯一源码，不移动目录、不增加生成或同步步骤。其余模块是否共用，以实际引用为准。

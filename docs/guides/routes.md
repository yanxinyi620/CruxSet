# 线路浏览与创作

微信小程序、本地 Web 和 Cloudflare Web 使用相同的线路角色与显示规则。两个 Web 共享前端代码；账户和数据分别由各自服务保存。

## 入口与页面

| 操作 | 三端入口 | 页面行为 |
| --- | --- | --- |
| 浏览公开线路 | 线路 → 选择墙面 → 浏览线路 → 选择线路 | 按角度、难度筛选，查看详情、切换上一条/下一条、全屏预览 |
| 查看自己的线路 | 我的 → 我的线路 → 展开墙面 → 点击线路 | 显示同一套完整详情，返回自己的线路列表 |
| 创建线路 | 创建 → 新建线路 → 选择已发布墙面 | 使用线路编辑器定线 |
| 编辑线路 | 我的 → 我的线路 → 编辑 | 使用同一个编辑器更新已有线路 |

三端各有两个站内查看入口、一个创建入口和一个编辑入口。详情和编辑器各自复用。小程序列表与详情为独立页面；Web 在墙面线路浏览页中切换列表与详情。小程序支持分享卡片直达；Web 的 `/problem/:id` 地址解析后进入完整详情。

公共浏览的上一条/下一条沿用当前筛选结果。从“我的线路”进入详情时按该墙面的线路编号切换，返回恢复原墙面分组；Web 将来源保存于地址中，刷新后仍可返回。

## 创建与保存

- 选择至少有两个岩点的公开墙面。
- 角度为 0°–70°，每 5° 一档；难度为 V0–V16。
- 选择角色并点击岩点，支持撤销和清空。一个岩点对应一个显式角色；线路至少包含起步和终点。
- 脚点规则包括跟随手点、指定脚点和全墙脚点。指定脚点需要选择至少一个脚点。
- 保存前在弹窗预览线路并填写名称、说明；说明最多 500 字。
- 修改已有线路保留线路编号。自己的线路列表同时提供删除操作。

## 墙图显示

| 区域 | 图片适配 | 小程序画布高度 | 两个 Web 画布高度 |
| --- | --- | --- | --- |
| 详情普通预览 | 等比铺满、居中，超出部分可拖动查看 | 620rpx | 320px |
| 创建/编辑 | 等比铺满、居中，支持拖动和缩放 | 屏幕高度减 420rpx，限制在 440–1100rpx | 420px |
| 详情全屏 | 等比铺满、居中 | 屏幕内可用空间 | 当前窗口高度 |
| 保存弹窗预览 | 等比完整容纳、居中 | 260rpx | 220px |

`rpx` 随设备宽度换算。墙面概览按图片比例计算高度，小程序限制在 320–900rpx；Web 按容器宽度与图片比例计算。

## 岩点与轮廓

| 角色 | 颜色 |
| --- | --- |
| 起步 | 绿色 `#3fb96a` |
| 脚点 | 黄色 `#f0c24b` |
| 手点 | 蓝色 `#3f7bd9` |
| 辅助 | 橙色 `#f08e63` |
| 终点 | 紫色 `#8f5fd9` |

- 已选岩点内部保留原图，无颜色填充。
- 沿岩点形状叠加 8px 白线、6px 角色彩线、2px 白线，并裁剪为只显示轮廓外侧。这些是画布逻辑像素线宽，设备像素比由画布处理。
- 多边形沿原顶点绘制；圆形按图片比例缩放，无最小显示半径。缩放改变轮廓形状尺寸，描边宽度保持固定。
- 未加入线路的岩点不绘制线路轮廓。
- 详情、创建/编辑、详情全屏和保存弹窗预览均对非线路区域叠加 50% 黑色遮罩。已选岩点内部及轮廓保持亮度；已选岩点重叠区域同样保持亮度。

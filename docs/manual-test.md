# Phase 1 人工测试清单

## 本地 Web（SQLite）

- [ ] 启动 FastAPI 与 `npm run web`，管理员可以登录。
- [ ] 手机与电脑在同一 Wi-Fi 时，使用电脑局域网 IP 打开 Web；不得使用手机的 `localhost`。
- [ ] 默认显示一面墙、一个公开 Layout、一个草稿 Layout 和四条线路。
- [ ] 新建墙面上传 JPEG/PNG/WebP 后，创建私有 Wall 与草稿 Layout。
- [ ] 重启 FastAPI 后本地创建内容仍存在。
- [ ] 草稿 Layout 不可定线；发布后锁定且可定线。
- [ ] 在日坛真实墙图 `web/public/assets/mock/ritan-spraywall-0822.jpg` 上运行自动识别：选择完整墙面 ROI 后结果非空，岩点/体积均落在 ROI 内，编号和坐标合法，墙外背景及 ROI 边界没有误检；刷新或重新进入草稿后可继续手工修正识别结果。
- [ ] 将识别区域输入为负数、零宽高或超出图片边界，确认自动回退整图并显示“识别区域无效，已回退整图”；修正为合法 ROI 后提示可消失。
- [ ] 自动识别默认执行形态学开运算；在需要保留细小/细节前景时验证关闭开运算或调整次数后的结果，并确认结果仍可手工修正。

## 本地 Mock 模式

- [ ] 保持 `runtimeMode = 'mock'`，不部署云函数也可编译并打开小程序。
- [ ] 在“创建”主页只看到“我的草稿”入口，而非直接显示草稿 Layout 列表。
- [ ] 在“创建 → 我的草稿”看到“日坛 Spraywall · 2026-09 标注草稿”；点击后显示日坛墙图，可添加岩点并发布。
- [ ] 发布后该 Layout 从“创建 → 我的草稿”消失；再次打开时只显示锁定状态。
- [ ] 重新编译小程序后，日坛草稿恢复为未发布的固定种子数据。
- [ ] 将 `runtimeMode` 改为 `'cloudbase'` 后重新编译，确认本地 Mock 墙面不再显示，再按 CloudBase 清单完成真实验收。
- [ ] “创建 → 新建线路”不显示“日坛 Spraywall · 本地标注草稿”；公开示例墙仍可选择。
- [ ] 公开 Layout 出现在“创建 → 新建线路”的 Layout 选择页；草稿或不足两个岩点的 Layout 不出现。
- [ ] 一个 Wall 存在多个公开 Layout 时，它们都可被选择并分别创建线路；发布新的 Layout 不影响旧 Layout 的定线能力。
- [ ] “我的”页不显示标注或新建 Layout 入口，只显示墙面 / Layout 状态及删除入口。
- [ ] 删除已发布 Layout 前提示其关联线路也会删除；确认后这些线路不再可浏览，取消不改变数据。
- [ ] 删除墙面前提示其所有 Layout 和线路都会删除；确认后全部子内容消失，取消不改变数据。
- [ ] 三个自定义 Tab 在 375px 宽度下无横向滚动，字体大小、间距和选中态与浏览器预览一致，最后一项内容不被 TabBar 遮挡。

## 微信开发者工具（CloudBase 模式）

- [ ] 底部固定显示“线路 / 创建 / 我的”三栏，切换后状态正确。
- [ ] 创建页可新建墙面、进入“我的草稿”继续未发布草稿；新建线路只可选择公开且至少有两个岩点的 Layout。
- [ ] 我的页仅显示当前用户创建的墙面。
- [ ] 打开项目根目录，页面路由无报错。
- [ ] 未配置 CloudBase 时 Demo 数据可浏览。
- [ ] 墙面图片加载失败时仍显示 Hold 与错误提示。
- [ ] 普通用户可查看已发布 Layout 的私有墙图。
- [ ] 普通用户无法取得未发布 Layout 或任意无关联私有文件的墙图地址。
- [ ] 管理员可预览未发布 Layout 的私有墙图。
- [ ] 按编号和名称搜索结果正确。
- [ ] 上一条/下一条不越出当前筛选条件。
- [ ] 随机线路一轮内不重复。
- [ ] 编辑页可选择五种角色，角色冲突自动迁移。
- [ ] 退出编辑页后草稿可恢复。
- [ ] 保存失败时草稿不丢失。

## 真机（至少 Android 1 台、iPhone 1 台）

- [ ] 单指拖动墙面。
- [ ] 双指缩放且锚点稳定。
- [ ] 缩放后点击密集 Hold 仍准确。
- [ ] 300–600 个 Hold 绘制无明显卡顿。
- [ ] Layout 管理员可连续添加、删除、Undo、调整位置和半径。
- [ ] 管理员可创建 Wall、上传墙图、创建首个 Layout 并进入标注页。
- [ ] 墙图上传、线路保存、分享链接可正常完成。
- [ ] 以非上传者账号浏览已发布 Layout 时，墙图可显示且存储权限仍为“仅创建者可读写”。
- [ ] 用户新建墙面默认显示为私有，且只在“我的墙面”中出现。
- [ ] 创建者发布 Layout 后，其他用户可在首页浏览该墙面及其公开 Layout。
- [ ] 非创建者不能读取私有墙面，也不能修改其他用户的 Wall 或 Layout。

## Layout 发布锁定

- [ ] 墙面创建者可打开未发布 Layout，添加岩点并发布。
- [ ] 发布后再次调用 `updateLayout`，云函数返回 `LAYOUT_LOCKED`，且数据库没有新增版本。
- [ ] 发布后再次调用 `publishLayout`，云函数返回 `LAYOUT_LOCKED`。
- [ ] 创建新的 Layout 后，可在不改变旧 Layout 和旧线路的前提下标注并发布。
- [ ] 墙面创建者可预览自己未发布 Layout 的墙图；其他非管理员账号不能取得该草稿墙图地址。
- [ ] 创建墙面后，从“创建 → 我的草稿”点击草稿的“继续标注”，无需配置开发者工具启动参数。
- [ ] 发布后回到“我的”，该 Layout 只显示“已发布并锁定”和删除入口；以旧编辑器链接打开时只能查看墙图和岩点。
- [ ] 删除已发布 Layout 后，其关联线路同时删除；删除墙面后，其 Layout 与线路同时删除。

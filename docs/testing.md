# 测试与验收

## 自动化检查

在仓库根目录运行：

```bash
npm ci --prefix wechat/cloudfunctions/adminWall  # 首次或依赖更新后
npm test
npm run build
npm run edge:typecheck
npx tsc -p web/tsconfig.json
npm run web:build
npm run web:build:local
npm run verify:phase1
```

`npm run build` 执行根项目和小程序 TypeScript 检查；Worker、Web 类型与两种页面构建分别检查。发布前使用 `npm run verify:phase1 -- --release`，该命令要求真实 AppID。

本地 API 和分割实验台分别运行 Python 测试（以下各段从仓库根目录开始）：

```bash
cd server
uv run pytest -q
```

分割实验台：

```bash
cd tools/segmentation-lab
uv run --extra test pytest -s -q
```

文档修改后还应检查 Markdown 相对链接、脚本名称和环境变量是否与仓库一致。当前权限与额度见[设计参考](reference.md)和各端指南。

## 三端线路页面与画布

按[线路使用说明](guides/routes.md)，分别在小程序、本地 Web、云端 Web 验证：

- [ ] 公共线路列表和我的线路都能打开完整详情；从我的线路返回恢复原分组，Web 刷新后来源仍有效。
- [ ] 公共详情按筛选结果切换上下条；独立地址与分享卡片可直达详情。
- [ ] 创建与编辑复用同一编辑器，角度、难度与角色选项一致。
- [ ] 横图、竖图在主画布和全屏等比铺满居中，拖动与缩放可查看超出区域；保存预览完整容纳。
- [ ] 详情、创建/编辑、全屏及保存预览的非线路区域均压暗 50%，岩点内部、重叠区域及轮廓保持亮度。
- [ ] 轮廓仅在外侧显示白彩白三层，内部无填充；小圆形岩点按比例显示，未选岩点无轮廓。

自动化覆盖：`tests/wall-image-fit.test.ts`、`tests/route-detail-navigation.test.ts`、`tests/miniprogram-outline-rendering.test.ts`、`tests/route-dimming.test.ts`。真机检查应覆盖 Android 和 iPhone。

## 本地 Web：完整创作（FastAPI、SQLite 与本地媒体）

- [ ] 启动 FastAPI 与 Web 后，管理员可以登录。
- [ ] 上传 JPEG、PNG 或 WebP 并创建私有 Wall。
- [ ] 私有 Wall 可标注岩点；至少两个岩点后可发布。
- [ ] 已发布 Wall 可浏览、定线，且墙图正常显示。
- [ ] 发布后不能修改 Wall 的墙图、几何或岩点。
- [ ] 已登录用户可创建、编辑和删除自己的线路；不能编辑或删除其他用户的线路。

## 小程序：CloudBase

- [ ] 首次启动、登录失败重试与分享直达正常，业务请求等待微信身份就绪。
- [ ] 普通用户只能创建线路；管理员可进入墙面上传、草稿与标注；非管理员直接进入页面或调用云函数也被拒绝。
- [ ] 超过单批数量的公开墙面、线路、个人内容和管理员用户列表不漏项。
- [ ] 从“全部”或指定角度/难度进入详情，上一条/下一条沿用筛选结果；全屏关闭与返回列表保持上下文。
- [ ] 名称、说明、角色和线路参数在中途离开后恢复；保存失败保留草稿，成功清理；新建和编辑草稿彼此隔离。
- [ ] 线路编辑/删除只对创建者或相应管理员开放，稳定编号在编辑后不变。
- [ ] 管理员上传相册 JPEG、PNG、WebP 和方向不同的相机图片，经转换后预览方向及岩点位置一致；重复提交/网络重试不重复建墙。
- [ ] 私有草稿支持手动增删移动、撤销/恢复、清空与保存；每次修改后保持当前缩放和平移。
- [ ] 轻量自动识别可取消，结果可修正和撤销；至少两个岩点才能发布；已发布墙面不能修改几何。
- [ ] 普通用户可查看并删除自己的墙面，不能删除他人墙面；管理员从独立管理中心查看全站墙面和用户。
- [ ] 删除前显示关联线路数量；确认后级联清理（包括他人线路），共享图片保留；大批量删除保留继续入口，媒体失败可以重试。
- [ ] 所有业务集合及 Storage 保持私有；共享图片只要存在合法公开/自有引用即可读取；无授权私有图片不可取。
- [ ] Android 与 iPhone 验证画布首次加载、单指拖动、双指缩放、抬起一指继续移动、密集岩点命中、全屏与弱网恢复。

`tests/miniprogram-parity-*.test.ts` 覆盖身份、页面状态、草稿、画布生命周期/手势、上传重试与管理确认；`tests/cloudbase-parity-lifecycle.test.ts` 覆盖实际云函数路径、分批列表、上传校验、发布锁定和删除恢复。自动测试和模板编译不能代替 CloudBase 联调及真机验收。

## Cloudflare Web：公开浏览、认证与线路写入

- [ ] 未登录访问者可浏览已发布的公开 Wall、墙图和线路；私有或未发布 Wall 不出现在公开接口和页面中。
- [ ] 用户可注册、登录、退出并更新资料；登录后可创建、编辑和删除自己的线路，不能编辑或删除其他用户的线路。
- [ ] 浏览器端不运行 AI 任务。
- [ ] 配置 R2 `MEDIA` 后，管理员可上传墙图、创建私有 Wall、标注岩点，并在至少两个岩点后发布；发布的 Wall 可公开浏览和定线。
- [ ] 未配置 `MEDIA` 时，管理员的上传、墙面创作、岩点标注和发布入口均禁用；公开浏览、认证和线路写入仍可用。

## 分割实验台发布验收

- [ ] 在实验台选择已保存校准结果并点击“发布到 CruxSet”。
- [ ] `web` 目标只在本机 Web 创建新的公开 Wall；`cloudbase` 目标只在 CloudBase 创建；`cloudflare` 目标只在 Cloudflare Web 创建新的公开 Wall。
- [ ] 本地管理员分别选择配置好的 `web`、`cloudbase`、`cloudflare` 发布，确认每个目标独立完成；本地普通创作者只允许 `web`，云端工作台只允许当前 Cloudflare 站点。
- [ ] 选择 `cloudbase` 后，原图大于 6 MB 时仍能完成直传 Storage；完整签名校准 JSON 也会直传 Storage，`segmentationPublish` 仅接收小于 100 KB 的 `payloadFileId` 请求，随后出现新的公开 Wall，岩点数量与校准结果一致。
- [ ] 在小程序 CloudBase 模式刷新公开墙面列表，能看到新 Wall、墙图和岩点，并可正常创建线路。
- [ ] 管理员可在小程序查看已发布墙面，确认后删除墙面及所有关联线路；旧发布回执不能恢复已删除墙面。
- [ ] 本地实验台再次显式发布会按目标协议处理；云端工作台重复提交同一已发布校准返回原回执，不新增 Wall。云端墙面已删除时旧回执不恢复墙面，需保存新校准。

## 授权管理交互（本地与云端）

跨平台申请自动测试：`tests/lab-publish-requests-ui.test.ts` 验证确认、路由选择、安全显示及防止重复点击；`tools/segmentation-lab/tests/test_publish_requests.py` 和 `edge/tests/lab-publish-requests.test.ts` 验证身份隔离、快照、审核、重试与目标管理员归属。

- [ ] 创作者在原发布按钮选择跨平台目标，确认提示管理员归属及不占本人墙面额度。
- [ ] 实验台说明上方显示申请列表；创作者看自己，管理员看全部，可预览、通过或拒绝。
- [ ] 修改或删除原校准后，申请预览仍为提交时的图片和岩点。
- [ ] 管理员通过后显示发布结果；失败后可重试，重复通过不重复建墙；申请人公开墙面用量不增加。
- [ ] 本地重启后申请仍在；云端只提供云端 Web、小程序两个目标。

- [ ] 在较长用户列表靠下的位置开通、撤销实验台权限，当前卡片及时更新，滚动位置不变。
- [ ] 保存期间只禁用当前用户的授权按钮；完成后恢复，用户名、邮箱和注册时间保留。
- [ ] 保存失败在当前卡片提示错误，按钮恢复可重试，不跳回页面顶部。
- [ ] 本地精简授权响应与云端完整用户响应均正常，授权不应覆盖其他用户资料字段。

## 云端实验台账户与授权

- [ ] 普通用户登录后不显示实验台入口，直接访问实验 API 返回 403；未登录返回 401。
- [ ] 管理员在“我的 → 管理中心 → 用户”开通实验台权限，目标显示“创作者”；普通用户不能调用授权管理接口。
- [ ] 获授权用户刷新“我的”或登录后可看到实验台入口，进入 `/segmentation-lab/` 无需再次登录。
- [ ] 获授权用户可上传、计算、保存校准、导出和公开发布自己的结果；无法读取、修改或发布他人的实验，无法管理用户或获得通用管理员墙面创作权限。
- [ ] 撤销权限后同一登录会话下一次实验 API 请求返回 403，刷新“我的”后入口消失；已发布墙面和原实验记录保留，重新授权后可继续访问原实验。
- [ ] 管理员默认保留实验台权限；本地 FastAPI 管理页面使用相同的实验台授权操作，分别管理本地账户。
- [ ] Web 与实验台请求使用同域 `/api/v1/`，返回权限错误时不误提示重新登录。

## 本地实验台权限与迁移

- [ ] 未登录实验 API 返回 401；未授权返回 403；普通授权用户可使用自己的实验。
- [ ] 其他用户（包括管理员）不能通过图片、候选、校准、SVG、删除或发布深链访问别人的实验。
- [ ] 无归属旧实验归管理员，已有 owner.json 不覆盖，原实验文件哈希不变。
- [ ] 本地发布墙面 ownerId 为当前用户；普通用户不能选择跨平台发布或触发外部成功回调。
- [ ] 授权撤销后同一会话立即失去访问权，重新授权后原实验仍可用。
- [ ] 私有图片与其他实验 API 返回 Cache-Control: no-store；8765 直连拒绝请求。

### 线路角度一致性

- 小程序线路列表筛选、新建线路、我的 → 我的线路 → 编辑线路，以及 Web 对应页面，统一提供 0°～70°、每 5° 一个选项（共 15 项）。筛选额外提供“全部”，默认“全部”；新建默认 0°；编辑和恢复草稿保留合法角度。
- 使用历史 `angleOptions: [20, 25]` 的墙面，确认以上入口仍显示全部 15 项，0°、5°、70° 均能新建、编辑保存和跨平台同步。非法角度（如 -5°、3°、75°）必须拒绝。
- 新墙面、分割发布的默认角度同样覆盖全部 15 项。线路选择和保存使用统一的 15 项角度。
- “我的”“我的线路”列表和线路详情只展示已有角度，无独立角度选择器；我的线路编辑复用新建线路编辑器。
- 上线需重新编译上传小程序，并部署 `saveProblem`、`updateProblem`、`routeSync`、`adminWall`、`segmentationPublish` 云函数；同步更新 Web/Edge 与本地分割发布工具。

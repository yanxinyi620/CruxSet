# 墙面与线路排序统一

## 行为

- 小程序和本地/云端 Web 的墙面列表、选墙列表、我的线路墙面分组及管理列表按 updatedAt 降序；相同时间按 ID 降序，稳定分页。
- 墙面内线路按编号升序；小程序我的线路在所有墙面读取完成后统一排序，消除异步返回顺序影响。
- 已公开墙面重复发布保留 updated_at，首次公开仍写入当前时间。覆盖普通发布和实验台已有回执路径。
- 不新增发布时间、不处理历史数据、不更改画布高度。

## 发布依赖

- CloudBase：先按 config/cloudbase.collections.json 配置新增排序索引，再部署 wallManager、adminWall 与小程序。
- Cloudflare：执行 0015_wall_update_order.sql（仅更新索引，不回填数据），部署 Worker 与 Web。
- 本地 Web：重新构建前端，无需后端数据迁移。
- 墙面分页游标改为 updatedAt；旧游标返回 INVALID_CURSOR，客户端重新读取第一页。线路分页接口协议不变，Web 在完整加载后按编号排序。
- 本次仅修改和验证源码，未执行线上部署或索引变更。

## 验证

85 个测试文件、455 项测试通过；主项目/小程序及 Edge 类型检查通过；云端和本地 Web 构建通过。新增回归验证覆盖分页与相同时间排序、首次及重复发布、CloudBase 列表排序和小程序异步加载后的分组顺序。独立代码复核未发现重要问题。

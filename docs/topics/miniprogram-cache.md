# 小程序浏览缓存

缓存入口：`services/browse-data.ts` 和 `services/personal-data.ts`。墙面首页、墙面概览、线路列表及详情，以及“我的”的线路数量和“我的线路”使用先缓存后更新；编辑、其他管理查询和用户权限查询使用严格读取缓存。

## 数据

- 成功读取后 30 秒内复用，不重复请求；同一请求并发合并。进行中的请求单独管理，不会因已完成数据的容量淘汰而重复发起。
- 超过 30 秒、但在额外 24 小时内的内容立即返回，同时后台更新。硬过期后必须重新请求。
- 可见页面订阅刷新结果，自动更新内容并保持筛选；隐藏/卸载时退订，丢弃已过期页面请求的返回结果。
- 每套数据缓存保留最近访问的 100 条已完成记录。命中会更新访问顺序；列表预存的详情只占用空余容量，并排在淘汰队列前面，保留进行中的父列表所需位置，不挤掉墙面或完整列表。
- 浏览数据使用一个本地存储键，按 JSON 的实际 UTF-8 字节计量，预算为 900 KiB，预留存储余量；过大记录跳过本地保存，不阻止内存读取。写入失败逐次舍弃较旧记录重试；连空数组都无法写入时尝试移除旧快照。
- `getCacheDiagnostics()` 提供最近 20 条恢复/保存诊断，包含状态、条数、字节数和重试次数；存储失败也记录到开发者控制台。诊断不包含用户 ID、缓存键或业务数据。
- 缓存键包含云端确认的用户 ID。冷启动仍需完成一次登录确认，随后可恢复该用户缓存；不以磁盘上旧用户 ID 直接授予访问。
- 网络失败保留未硬过期内容；明确不存在或无权限则移除。列表刷新发现已删除对象时，同时移除对应详情缓存。
- 线路保存、修改、删除前后，失效两套缓存中相关墙面的线路列表、个人线路汇总、对应线路详情和墙面汇总计数，保留其他墙面线路列表、墙面详情及图片。编辑/删除从已有详情或完整列表识别所属墙面，无法确定时保守失效所有线路列表。
- 真正的墙面、权限/资料写入继续清空严格缓存与浏览缓存。读写操作明确分类；例如仅查询删除墙面的影响、最后取消删除，不再清缓存。本地持久化立即同步失效，写入完成通知可见页重读。旧请求不会回填被失效的记录。

## 刷新与页面状态

- 墙面首页、浏览线路和我的线路开启原生下拉刷新。主动刷新绕过 30 秒新鲜期并等待网络结果，同一进行中的请求仍会合并；保留角度/难度筛选及个人分组展开状态。
- 后台更新由读取触发，不是每 30 秒自动轮询。页面静置时不会持续请求。
- 浏览页、我的墙面、草稿及管理页：首次没有内容才显示加载；再次读取保留已有内容（包括成功的空列表），以局部更新或错误提示反馈。权限仍使用严格查询，明确撤销时清除相应数据，不能通过筛选重新显示旧线路。
- 页面隐藏或卸载时退订并丢弃过时响应；尚未开始的下拉刷新不会在页面隐藏后启动。下拉刷新中若发生写入失效，会忽略旧结果并重读后再结束刷新，防止旧数据覆盖新保存的内容。

## 我的与我的线路

- 两个页面共用按当前已确认用户隔离的完整个人线路列表，首次仍需查询；不以已浏览的公开线路推断个人线路数量。列表整体保存为一条记录，避免线路较多时挤掉列表自身和墙面缓存。
- “我的线路”复用浏览墙面详情，同墙线路只读取一次墙面，按墙面更新时间、线路编号排序。已有内容及空列表再次显示时不重新开启加载提示；后台更新保留分组展开状态。
- “我的”管理员身份单独严格查询，不阻塞线路数量；查询失败关闭管理入口并提示。
- 普通网络刷新失败保留已有内容并提示重试；明确无权限或删除时移除对应个人列表或墙面分组。隐藏/卸载页面退订，忽略已经过时的页面请求。

## 图片

- CloudBase 文件按用户 ID 和文件标识持久化；最多 12 张，总量 30 MB，最长 7 天，淘汰较久未访问文件。
- 文件位于 `wx.env.USER_DATA_PATH/cruxset-images`；只清理缓存自有文件，不处理草稿、其他应用文件或云端图片。
- 保存失败、配额不足时使用本次下载的临时文件；文件丢失时重新下载。解码失败沿用原有失效重试机制。
- 普通 HTTP 地址使用 10 分钟内存缓存，避免将可能原地更新的地址永久固定。

## 使用与验证

直接在原项目 `wechat` 编译。首次访问建立缓存，后续页面切换及重新进入复用缓存；首次登录和首次图片下载仍需等待网络。这不是离线授权，也不保证数据实时同步。

自动化测试覆盖缓存时效、持久化重载、用户隔离、并发/写入竞争、后台刷新后的页面更新、隐藏退订、删除详情失效、图片数量/字节/年龄淘汰、文件丢失和配额失败。

缓存加固回归另外覆盖 120 条普通线路、LRU 与预存详情优先级、只读操作不失效、按墙面失效、强制刷新及写入交错、权限撤销后的筛选、真实 UTF-8 预算与持久化缩减重试。

真机验收应分别测量首次加载、页面切换及重新进入的耗时，并验证弱网与离线情况下的提示。

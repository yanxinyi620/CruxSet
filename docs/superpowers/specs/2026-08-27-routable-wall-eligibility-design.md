# 可设置线路墙面资格设计

## 目标

“创建 → 新建线路”只显示能够实际设置线路的墙面；未标注或未发布的 Layout 草稿仅用于墙面管理和标注，不作为线路目标。

## 资格规则

一面墙面可出现在“新建线路”列表，当且仅当：

1. 调用者拥有该墙面，或该墙面为公开墙面；
2. 墙面存在 `activeLayoutId`；
3. 该 Layout 最新快照为 `published: true`；
4. 该 Layout 至少有两个 Hold。

两个 Hold 是最低要求，因为线路需要不同的 Start 与 Finish。页面继续去重：用户自己的公开墙面只显示一次。

## 用户体验

- “我的”继续显示未发布草稿，并提供“开始标注”。
- “创建”不显示任何草稿墙面；没有合格墙面时显示“先发布一个已标注 Layout，再开始设置线路”。
- 已发布、岩点充足的自己的私有墙面和他人的公开墙面可用于创建线路。

## 实现与验证

页面使用既有 `getLayout(activeLayoutId)` 服务取得当前 Layout，按资格规则过滤。加载失败或 Layout 不合格时排除该墙面，不把错误的草稿暴露为线路选择项。

新增纯函数测试覆盖：空 active Layout、草稿、已发布但少于两个 Hold、合格 Layout 和去重行为。Mock 种子中的日坛草稿必须被排除，公开示例墙必须保留。

## 非目标

- 不改变 Wall 或 Layout 的服务端权限。
- 不允许用未发布 Layout 创建 Problem。
- 不在本次增加 Layout 发布时至少两个 Hold 的服务端限制；该约束仅定义线路选择资格。

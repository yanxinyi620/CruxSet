# 云端实验台独立授权

用户已确认：共享 Cloudflare Web 账户和同域会话；管理员保留访问能力，普通用户由管理员开通或撤销实验台授权。授权包含计算、校准、导出及公开发布自己的校准结果，不授予网站管理或通用墙面创作权限。

在现有 admins 账户表增加 lab_enabled，默认 0。管理员角色具有隐含实验台权限。管理员列表展示普通用户/创作者/管理员，普通用户提供开通或撤销按钮；管理员显示默认开放，无需切换。FastAPI 不声明授权管理能力，因此共享 Web 在本地不展示该操作。

新增同域 PATCH /api/v1/auth/admin/users/:id/lab-access，严格接受 enabled 布尔值，仅管理员可调用；不存在账户返回 404，管理员目标返回 409。会话每次请求从数据库读取权限，因此撤销后下一次 API 请求即拒绝；不删除历史实验和公开墙面，已启动机器任务可完成，但不能自动发布。

Web API 使用相对路径，与 /segmentation-lab/ 共用当前域名的 HttpOnly 会话。原 api 子域的历史会话不会迁移，用户可能需要在主域重新登录。bootstrap 返回有效实验台能力及管理员授权管理能力。用户入口仅由认证状态和有效能力决定，不以管理员身份限定。

继续按 owner_id 隔离实验、候选、校准及发布，保留 runner 独立鉴权。403 显示权限不足而不是再次登录提示。小程序与本地实验台不改。

验证：数据库默认值/约束；同一会话授权前后能力变化；未登录/普通用户/管理员访问矩阵；拒绝非法和跨域修改；获授权非管理员全流程及跨用户隔离；撤销后所有个人实验接口拒绝；前端能力入口、授权按钮和同域请求；全量 TypeScript 测试及 Web/Workers 构建。

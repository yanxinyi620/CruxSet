# 墙面和线路统一排序

用户确认简化方案：所有墙面按现有 updatedAt 降序，墙面内线路按编号升序；不新增发布时间、不回填历史数据。时间相同按 ID 降序稳定排序。草稿继续按更新时间排列，不另分已发布/草稿。

小程序公共墙面查询、我的墙面与管理查询统一排序；我的线路等待墙面加载完成后排序分组和线路。两个 Web 共用排序规则。云端墙面查询、分页游标和索引使用 updated_at；线路页面已有编号排序保持。普通发布及实验台已有回执重复发布保留已公开墙面的 updated_at，私有墙面的首次公开仍更新时间。

验证：真实 SQLite 分页及重复发布测试、小程序异步乱序加载测试、全量 Vitest、类型检查和两种 Web 构建。不自动部署。

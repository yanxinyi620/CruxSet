# 线路浏览页设计

## 目标

将线路入口分为墙面信息页与线路浏览页。用户先选择墙面、查看墙面信息，再明确进入该墙面的线路浏览。

## 页面与交互

1. 线路首页继续列出公开墙面。
2. 选择墙面后，墙面详情仅显示名称、岩点数量和墙面预览图；不列出线路。页面提供“浏览线路”按钮。
3. 浏览线路页显示该墙面的线路：顶部有角度与难度两个筛选按钮；未筛选时显示全部线路列表。
4. 点击列表线路后，当前页面改为该线路的墙图预览和线路信息，底部提供“上一条”和“下一条”按钮，按当前筛选后的顺序切换。边界按钮禁用。
5. 从线路详情返回回到该墙的线路列表；从线路列表返回回到墙面信息。

## 数据与显示规则

- 筛选在客户端对已加载的墙面线路执行，不引入新 API。
- 角度使用当前系统的 0°–70°、每 5°；难度使用 V0–V16。
- 无匹配线路时显示明确空状态。
- 路线预览继续使用现有 `WallCanvasView`，不启用原图暗化。

## 验证

- 路由支持墙面线路浏览页。
- 测试确保墙面详情不再直接包含线路行，且线路浏览页有筛选、列表和前后切换入口。
- 运行针对性 Web 测试和生产构建。

# 小程序二级/三级页面向 Web 对齐

## 范围

仅修改 `wechat/miniprogram/` 及对应测试，Web 保持不变。对齐线路列表、线路详情、创建线路编辑器和小程序画布表现。

## 设计

线路列表使用与 Web 一致的角度/难度筛选语义：角度和难度均通过弹层选择，默认“全部”，难度覆盖 V0-V12，筛选结果保留当前墙面上下文。

线路详情沿用 Web 的大图预览、线路元信息、角色图例、说明和前后线路导航，保持只读。

统一 `wall-canvas` 绘制模型：墙图作为底图，岩点按类型绘制轮廓与填充；线路角色使用 Web 对应颜色，未分配岩点使用中性轮廓，选中态清晰区分。编辑器和详情页通过同一套角色映射展示。

创建线路编辑器采用画布优先布局，元信息、角色选择、脚点规则、名称说明和操作区顺序向 Web 靠拢，保留微信原生 picker 与触摸交互。

## 验收

- Web 文件无变化。
- 小程序线路列表筛选范围和方式与 Web 一致。
- 线路详情和创建编辑器使用统一的墙图/岩点轮廓表现。
- 岩点不再统一显示为蓝色实心圆。
- 相关专项测试、类型检查和 Web 构建通过。

# 退役根目录共享层设计

## 目标

删除根目录 `src/` 中未被 Web 或微信小程序运行时使用的旧共享代码。测试改为直接覆盖各端实际运行的实现，不改变产品功能、数据模型或发布流程。

## 范围

- 小程序专属规则测试迁移为导入 `wechat/miniprogram/` 的对应实现。
- Web 专属规则测试迁移为导入 `web/src/` 的对应实现。
- 两端独立实现的同一业务规则，各自保留等价测试。
- 仅服务于旧共享层且没有当前实现对应物的仓储、用户映射、演示数据和线路服务测试随旧代码删除。
- 删除 `src/`、根目录 `src/index.ts` 的导出入口，以及所有失效引用。

## 测试归属

小程序：岩点命中、坐标转换、手势、线路编辑、浏览筛选、随机线路、墙面可用条件和页面路由相关规则。

Web：Web 创作台、草稿编辑、上传、登录、管理和 API 交互规则。

两端共有行为：仅在两端都存在独立实现时，在两端分别保留等价测试；不再建立新的根目录共享运行时模块。

## 删除规则

以下内容在确认没有实际端依赖后删除：旧领域类型、演示数据、内存仓储、线路服务、用户映射和它们专属测试。历史设计文档只在其描述旧目录时保留，不作为运行依赖修改。

## 验收

1. 仓库不再包含根目录 `src/`。
2. 根目录及端侧测试不存在对 `../src/` 或 `src/` 的代码导入。
3. `npm test` 通过。
4. `npm run build` 通过。
5. 小程序和 Web 的现有业务行为未发生变化。

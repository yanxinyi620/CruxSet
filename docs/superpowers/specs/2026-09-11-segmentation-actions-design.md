# 本地实验台与 GitHub Actions 云端链路并行设计

状态：用户已批准实现。远端验证结果另行记录，不以设计文档代替运行证据。

## 目标与范围

保留本地实验台完整功能和启动方式，增加无需本地服务在线的云端链路：浏览器上传和配置参数，Worker 创建任务，GitHub Actions 运行共享 Python 分割核心，结果经 Worker 写入 R2、状态写入 D1，浏览器查看、人工校准和发布 Cloudflare 墙面。

本地数据仍保存在 SEG_LAB_DATA_DIR；本地 web/cloudbase/cloudflare 三个发布目标和 SAM3 可用性检测保持原有行为。云端数据独立存储，初版支持 sam2、sam2_tiled，云端发布目标为当前 Cloudflare 站点。两端不自动同步实验或校准。

## 方案选择

推荐共享页面和分割核心、分离 API 与存储。相比复制整套实验台，避免校准功能分叉；相比让本地 API 同时管理云端任务，云端使用不依赖本机在线。

## 页面与访问

云端入口为 /segmentation-lab/，复用现有上传裁剪、参数配置、结果查看、校准编辑、撤销重做、保存独立校准记录、继续编辑、SVG 导出与删除交互。通过显式运行配置设置页面路径、API 前缀、模型能力和发布目标，不在浏览器猜测服务类型。本地默认路径与行为保持兼容。

云端 API 前缀为 /api/v1/segmentation-lab，复用现有管理员会话；普通用户和未登录用户不能读取或操作实验数据。页面显示登录失效、任务阶段和可重试错误。变更操作检查同源请求，云端入口在现有管理员界面提供链接。

## 存储与数据契约

新增实验、任务和校准 D1 表，使用独立 lab_ 前缀，不改写本地记录。记录创建者、时间、图片尺寸与哈希、任务参数、状态、执行尝试标识、GitHub run 标识、错误和对象引用。校准保存为独立快照，发布回执绑定该快照。

R2 使用私有 lab/ 前缀，保存裁剪后的原图、任务候选 JSON、兼容 PNG 包、WebP 展示图和校准 JSON。不能通过现有公开媒体 API 绕过实验权限。实验读取使用受鉴权 Worker 接口；发布时将展示图复制到独立公开媒体对象，删除实验不会破坏已发布墙面。

候选 JSON 保留既有 polygon、bbox、area、score 和 metadata 语义。坐标始终基于裁剪后输入图尺寸；发布沿用现有归一化约定。D1 不存逐像素 mask。对象写入完成并通过必要校验后才提交可见引用，失败对象由清理流程回收。

## 任务协议

任务阶段为 queued、running、succeeded、failed、timed_out；dispatch 错误归入 failed 并给出可重试原因。重试产生新的任务，不覆盖旧结果。GitHub workflow_dispatch 只传任务标识和尝试标识，仓库、分支、工作流由 Worker 服务端固定配置。

Actions 用服务端密钥认证领取任务，Worker 原子确认该尝试的执行所有权，返回短期任务凭据。该凭据仅允许读取对应输入、写入对应输出和回报进度，不提供整个 R2 桶或 D1 的凭据。重复触发不能同时领取同一任务。

独立 Python 执行入口下载输入、验证实际图像与参数、调用现有 BenchmarkService、生成 WebP 和输出清单，上传结果并完成回调。回调必须绑定任务、尝试和执行身份；重复完成幂等，旧尝试不能覆盖终态。模型加载、分割、后处理、上传分阶段展示，不将适配器的 100% 直接解释为云端完成。

Worker 定时检查排队和执行期限，修复 runner 被终止或回调丢失造成的悬挂状态。正常异常由执行器回报；进程强制终止通过超时收敛。初版排队超过 30 分钟、执行超过 120 分钟标记超时；workflow job 超时设置为 90 分钟。迟到上传和回调不能恢复已失效任务。

删除运行中的任务先使执行凭据失效，再清理对象；远端进程即使继续短暂运行也不能重新创建已删除记录。清理失败保留可重试状态。删除来源任务保留已保存校准及其几何，删除整个实验才删除其校准。发布墙面独立存在。

## 初版资源约束

采用 ubuntu-24.04、Python 3.11、CPU PyTorch，每个 job 执行一个任务、4 CPU 线程。拆分 SAM2 专用可选依赖，现有 models 安装方式继续可用；使用锁定依赖和模型 revision，并缓存下载文件。缓存不存实验图片、任务凭据或结果。

云端上传 JPEG/PNG，初版限制 20 MiB、最长边 4096、总像素不超过 16,777,216；超限明确提示裁剪或缩小，不静默改变几何。Worker 校验大小、格式和图像头尺寸，执行器解码后再次验证。参数采用白名单，点密度 8–64、批量 1–8、质量和稳定度阈值 0–1、内部裁剪层固定 0。每位管理员最多同时保留两个未完成任务。候选和校准请求限制字节数、候选数量和顶点数，拒绝非有限或越界坐标。

## 发布

推理只产生实验结果，不自动创建公开墙面。管理员在校准列表显式发布，Worker 从保存的校准快照和展示图创建墙面，使用当前管理员作为所有者并保存幂等回执。尽量提取共享发布服务，保留既有本地 HMAC 发布端点的请求和响应兼容性。云端浏览器不持有发布签名密钥。

## 验证与交付

1. 本地实验台完整测试通过，覆盖路径配置、本地模型与三个发布目标兼容性。
2. Worker 测试覆盖管理员权限、私有对象隔离、任务领取竞争、dispatch 失败、重复和过期回调、超时、删除后回调、校准保存与幂等发布。
3. 执行器测试覆盖下载校验、参数拒绝、推理失败、上传失败及成功回调；使用小型确定性候选验证协议。
4. 类型检查、Web 构建和 Worker dry-run 通过，浏览器验证本地与云端上传至校准发布流程。
5. 当前采样修正版在 Actions 上实际跑典型图和 4K 图，分别记录 sam2/sam2_tiled、冷启动/缓存命中的耗时、峰值 RSS、磁盘与结果。旧版约 2.47 GiB 基准只作参考，不作为新版验收数据。
6. 文档明确新增迁移、Worker/GitHub Secrets、启用步骤、任务限制与回滚方式。远端未验证时明确报告，不把模拟测试等同于实际部署成功。

验收标准：本机实验台完整可用；关闭本地服务后，管理员仍能在云端完成上传、任务执行、结果查看、人工校准和 Cloudflare 墙面发布；未授权访问与失败任务不会泄露数据或形成永久运行状态。

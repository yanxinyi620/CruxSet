# 线路浏览器全屏预览设计

## 目标

在线路页打开墙面、进入“浏览线路”并选中某条线路后的详情视图中，支持点击墙面画布以全屏查看该线路及其岩点标记。

## 范围

- 仅作用于线路浏览器中的已选线路详情视图。
- 不作用于“我的线路”进入的独立线路详情页、墙面详情页或编辑器。
- 点击普通画布打开全屏覆盖层；点击全屏画布关闭。
- 全屏与普通视图显示同一墙面图片、当前线路岩点角色标记和配色。

## 体验

普通画布下方显示“点击查看全屏”提示。全屏覆盖层占满手机视口，使用深色背景和更大的按比例画布；不会写入浏览器历史或改变当前选中的线路。

全屏画布保留已有的单指拖动、双指缩放和滚轮缩放。仅未发生拖动或缩放的单指轻点会关闭预览；手势不触发关闭。关闭后销毁全屏画布与事件监听，再次打开创建新的视图。

## 实现边界

在页面渲染层维护短暂的“全屏预览已打开”状态，普通预览和全屏预览分别拥有独立 `WallCanvasView` 实例。扩展 `WallCanvasView` 的可选轻点回调，以便全屏实例关闭预览；普通实例的轻点回调打开预览。组件继续使用现有画布的移动阈值与双指手势判定，避免重复实现手势逻辑。

## 验证

- 单元测试确认画布只在轻点时调用轻点回调，拖动或双指缩放不会调用。
- 路线浏览器测试确认选中线路详情包含全屏入口、覆盖层与关闭标记。
- 运行完整前端测试、TypeScript 检查和生产构建，确认不影响现有路线浏览、筛选和画布交互。

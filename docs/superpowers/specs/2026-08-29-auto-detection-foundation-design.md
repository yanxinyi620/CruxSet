# 自动识别基础修正设计

## 目标

改善 Web 端“创建 → 我的草稿 → 自动识别”在真实攀岩墙照片上的基础识别质量，优先降低小岩点漏检、墙外区域误检、宽高比例失真和参数不可调造成的问题。

本阶段不接入机器学习模型，不实现候选确认工作流，也不改变发布和 Layout 锁定规则。

## 当前问题

当前实现位于 `web/src/auto-detect.ts`，流程是：整图缩放到最大边 768 像素 → 以高饱和度或低明度生成前景掩码 → 十字形态学开运算 → 4-连通域 → 固定比例过滤 → 按外接框大小区分岩点和体积。

真实墙图存在墙外区域、透视、多平面、木板纹理、螺丝孔、阴影和相邻岩点。当前固定整图比例阈值会漏掉缩小后的小岩点，整图检测会增加误检，按宽度计算半径会使非正方形图像产生偏差。

## 设计方案

### 1. 墙面区域输入

自动识别函数增加可选的归一化 ROI 参数：`x/y/width/height`。默认使用整图，保持现有 API 兼容；编辑器第一次使用自动识别时允许用户通过简单矩形裁剪指定墙面区域，识别仅在 ROI 内执行，结果再映射回整图归一化坐标。

本阶段采用矩形 ROI，不做自动四边检测和透视校正。矩形裁剪可以立即排除照片中的墙外区域，同时为后续透视校正保留清晰接口。

### 2. 分辨率与过滤

分析分辨率仍需限制以避免浏览器卡顿，但最小组件不再使用固定的全图面积比例作为唯一条件。过滤条件改为同时基于分析像素尺寸和组件尺寸，并保留可调参数：

- `maxDim` 默认提高到 1280；
- `minComponentPixels` 控制分析图中的最小面积；
- `minSidePixels` 控制最小边长；
- 面积比例只作为极端大块背景的辅助过滤；
- ROI 面积作为比例计算分母，而不是原始整图面积。

这样小岩点的可见尺寸由分辨率控制，不会因墙面照片整体尺寸变化而被固定比例误删。

### 3. 几何计算

所有组件保留原始分析图中的 `bbox`，并将中心、半径、polygon 一并映射回整图归一化坐标。半径采用宽高归一化后的等效尺寸，避免图片宽高比导致分类和显示变形。polygon 每个点都必须经过同一 ROI 映射。

组件分类仍保留启发式 `hold / volume`，但基于组件的等效尺寸而不是只看宽度；分类阈值继续暴露为选项，并在界面提示这是实验性分类。

### 4. 误检控制

在不引入模型的前提下，增加以下低风险控制：

- 对 ROI 边界组件提供可选丢弃规则，避免墙外边缘被识别；
- 保留高饱和度与低明度两个独立掩码统计，便于后续调参；
- 保持形态学操作次数可配置，默认不对过小候选做过强腐蚀；
- 对相邻组件只做保守过滤，不在本阶段引入复杂分水岭算法。

### 5. 编辑器交互

自动识别按钮旁增加“识别区域”入口。用户可以设置或重置矩形区域；区域状态仅保存在当前草稿编辑会话中，不写入 Layout 数据模型。点击自动识别时显示处理中状态，识别结束显示数量和 ROI 信息。

当前“自动识别会替换已有标注”的行为本阶段暂不改变，候选层将在阶段二单独实现。

## 数据流

```text
墙图 URL
  → 加载原图
  → 选择/读取归一化矩形 ROI
  → 按 maxDim 生成分析图
  → ROI 内生成前景掩码
  → 连通域与几何统计
  → 组件过滤与 hold/volume 分类
  → 坐标映射回整图
  → LayoutEditor
  → DraftCanvas 绘制
```

## 测试方案

1. 保留现有纯像素单元测试，补充小尺寸候选、非正方形图像、ROI 坐标映射、ROI 边界和宽高归一化测试。
2. 增加真实墙图回归样例，至少验证：结果数量大于零、结果均在 ROI 内、坐标范围合法、没有大量墙外边缘误检。
3. 增加参数测试，确认提高 `maxDim` 和降低最小组件阈值确实能够保留小岩点。
4. 运行全部 Vitest、TypeScript 检查和 Web 构建。

本阶段不以“识别全部岩点”为验收标准，因为启发式算法无法达到模型级召回率；验收重点是可控、可解释、不会因分辨率和 ROI 产生明显系统性错误。

## 错误处理

- 图片加载失败时保持现有提示，不修改草稿数据。
- ROI 无效时回退整图并提示用户。
- 识别无结果时保留现有岩点，不写入空结果。
- 识别过程中禁止重复点击，完成或失败后恢复按钮状态。

## 后续兼容性

识别器继续输出现有 `Hold` 结构，并可携带 `bbox`、`polygon`。后续阶段可以在不修改编辑器核心逻辑的前提下，将启发式实现替换为实例分割实现。ROI 类型和识别结果元数据应保持独立，避免把临时识别参数写入发布 Layout。

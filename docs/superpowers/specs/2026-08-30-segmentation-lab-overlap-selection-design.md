# Segmentation Lab 重叠岩点选择设计

## 目标

人工校准页按 polygon 面积控制 SVG 层级：大体积位于底层，小岩点位于上层。用户单击两者的重叠区域时，浏览器应默认选中视觉上层的小岩点。

## 根因

SVG 使用文档顺序决定层级，后绘制的元素位于上层并优先接收指针事件。当前页面按面积升序生成 polygon，导致小岩点先绘制、大体积后绘制；因此实际层级和测试名称表达的意图相反，重叠区域会被大体积截获。

## 设计

保留现有 `polygonArea` 面积计算与 polygon 点击处理，只将渲染排序改为面积降序：

1. 大面积 polygon 先写入 SVG，形成底层体积。
2. 小面积 polygon 后写入 SVG，形成上层岩点。
3. 继续使用浏览器原生 SVG 命中规则，使重叠区域默认命中后绘制的小岩点。

不增加对象类型、层级字段或自定义点内判断，不修改后端接口与保存格式。

## 测试

更新人工校准页的回归测试，明确断言渲染使用面积降序。测试名称与断言都应表达“大 polygon 在小 polygon 之前渲染”，防止以后再次反转 SVG 层级。

运行该回归测试，并运行 `tools/segmentation-lab` 完整测试套件，确认没有影响候选加载、新增岩点、删除和保存校准结果。

# 线路编辑模式

## 目标

“我的 → 我的线路”中的编辑入口复用现有新建线路编辑器。用户可在保留原线路编号的前提下修改点位、角度、难度、脚点规则、名称与说明。

## 页面与状态

编辑入口携带线路 ID 进入 `problem-editor` 的编辑模式。编辑器读取原线路与墙面，恢复原有点位分配和元数据；页面标题为“编辑线路”，保存按钮为“保存修改”，编号只读展示。

## 保存规则

保存请求更新原线路，不创建新线路。编号、墙面 ID、创建人和创建时间保持不变。角度必须是 0–70 的 5° 步进；当角度非 0 时，还必须属于该墙面可用角度。这样可编辑历史 0° 数据，同时阻止新增不合法角度。

## 兼容与错误处理

历史 0° 线路可以直接修改名称和说明。无权限、线路不存在或非法输入时显示明确错误且保留编辑内容。

## 验证

测试更新接口对 0° 历史线路和墙面允许角度的处理；测试编辑模式保留编号且更新同一线路。构建 Web 和 TypeScript 项目。

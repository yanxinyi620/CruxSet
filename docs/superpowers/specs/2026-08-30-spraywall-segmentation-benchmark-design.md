# Spraywall 双模型分割基准台设计

日期：2026-08-30  
状态：待用户书面复核

## 1. 背景

CruxSet 当前的自动识别使用基于颜色、明度、形态学与连通域的启发式算法。它无法可靠区分岩点、木板、螺丝、阴影和大型造型，真实墙图上的轮廓与召回效果不足。

本阶段不修改 CruxSet 主程序，而是制作一个独立的桌面分割验证器。验证器在同一张固定 Spraywall 照片上比较 SAM 3 与 SAM 2.1，先自动生成全墙实例候选，再通过人工交互完成校正。项目以真实校正成本选择最终分割方案，确认效果后再另行设计 CruxSet 集成。

## 2. 目标与成功标准

### 2.1 目标

- 在无 NVIDIA GPU 的电脑上离线运行，允许单次推理等待 5–10 分钟或更久。
- SAM 3 与 SAM 2.1 使用同一输入图、墙面 ROI 和后处理约束，分别生成候选结果。
- 支持完整人工校正：补加、删除、正负提示点、框选重算、候选切换、拆分、合并、确认、撤销和重做。
- 保留模型原始二值 mask，并生成 SVG polygon 作为可编辑交互层。
- 自动记录编辑过程并生成模型效果报告。
- 导出 PNG masks、SVG 与独立 JSON，不适配当前 CruxSet 数据格式。

### 2.2 成功标准

验证器必须能完成一次真实全墙工作流：打开图片、运行至少一个模型、人工补全全部岩点并导出结果。某一模型失败时，另一个模型和人工编辑功能仍可继续使用。

模型选型按以下顺序评估：

1. 自动候选对最终确认岩点的召回率；
2. 自动 mask 与最终 mask 的轮廓质量；
3. 完成全墙校正所需的编辑操作数和总时间。

最终推荐召回率足够且人工校正成本最低的方案，不预设 SAM 3 或 SAM 2.1 必然胜出。

## 3. 范围

### 3.1 包含

- 单张固定墙图与矩形墙面 ROI；
- CPU 离线推理；
- SAM 3 文本提示和示例框提示；
- SAM 2.1 Automatic Mask Generation；
- 每个模型独立的可调推理参数；
- 统一候选后处理、结果比较和合并视图；
- SVG 桌面校正工作台；
- 实验快照、自动保存、编辑日志与结果报告；
- PNG mask、SVG、JSON 导出。

### 3.2 不包含

- CruxSet 数据结构、岩点 ID 或 API 适配；
- 小程序或移动端集成；
- 云端部署；
- 模型训练、微调或自建标注集；
- 岩点类型、颜色、难度或抓法识别；
- 多墙、多用户和权限管理；
- 视频与墙面角度变化处理。

## 4. 技术路线

### 4.1 双模型分支

SAM 3 分支接受简短文本提示（默认英文 `climbing hold`）及一个或多个用户框选的正示例。它输出与提示匹配的实例 mask、分数与边界框。文本和示例应分别保存，允许单独运行和比较。

SAM 2.1 分支使用 Automatic Mask Generation，在工作图上布置密集点网格并按需启用多尺度裁剪。它不负责理解“岩点”语义，只产生通用实例候选。

两条分支必须通过适配器输出统一的 `RawCandidate` 结构，模型特有数据放入 `metadata`，避免后处理与编辑器依赖具体模型。

```text
原始墙图
  ├─ 工作图与 ROI → SAM 3 → RawCandidate[]
  └─ 工作图与 ROI → SAM 2.1 → RawCandidate[]
                               ↓
                       统一后处理与快照
                               ↓
                        SVG 人工校正工作台
```

### 4.2 图像与坐标

- 原图保持不变，用于最终导出和坐标基准。
- 模型使用保持宽高比的工作图。每次实验记录工作图尺寸和缩放关系。
- 内部几何以原图像素坐标为权威坐标；SVG 使用与原图一致的 `viewBox`。
- 导出时同时提供原图像素坐标，归一化坐标留作通用附加字段。
- 墙面 ROI 之外的 mask 必须裁掉，接触 ROI 边缘的候选保留但标记为边缘候选，交由用户确认。

### 4.3 后处理

统一后处理执行以下步骤：

1. 清除小孤岛和填补可配置的小孔洞；
2. 按面积上下限过滤明显噪声和整墙背景；
3. 使用 mask IoU 与包含关系抑制同一模型内的重复候选；
4. 计算跨模型候选对应关系，但保留两份原始 mask；
5. 从 mask 提取外轮廓和孔洞；
6. 为 SVG 生成带误差上限的简化 polygon；
7. 保存原始 mask、简化 polygon、分数、来源、参数与过滤原因。

跨模型“合并结果”是比较视图和候选集合，不对两张 mask 做不可逆的像素并集。用户确认时明确选择一个候选或通过交互重新生成最终 mask。

## 5. 数据设计

### 5.1 实验快照

每次运行创建独立实验目录，包含：

- 输入图片指纹、尺寸和 ROI；
- 模型名称、权重版本、运行库版本和完整参数；
- 开始时间、结束时间、耗时、峰值内存和运行状态；
- 原始候选、过滤后的候选及过滤原因；
- 编辑日志、当前确认结果与生成的评估报告。

新实验不得覆盖旧实验。参数无结果或推理失败时，也要保存失败状态和诊断信息，但不得覆盖最近一次成功结果。

### 5.2 候选与最终实例

候选至少包含：临时 ID、模型来源、二值 mask 路径、原图像素 bbox、面积、模型分数、后处理分数、SVG 路径和状态。

最终实例包含：独立临时 ID、最终 mask、SVG 轮廓、来源候选列表和编辑历史。本阶段不生成 CruxSet 的 `H001` 等正式 ID。

## 6. 人工校正工作台

### 6.1 页面结构

- 顶部：打开图片、设置 ROI、选择模型、运行和查看耗时；
- 左侧：合并、SAM 3、SAM 2.1、并排四种查看模式及状态筛选；
- 中央：墙图与 SVG 覆盖层，支持缩放和平移；
- 右侧：当前候选信息和修正工具；
- 底部：自动保存状态、撤销/重做和导出入口。

### 6.2 视觉状态

- 绿色实线：已确认；
- 黄色虚线：待处理；
- 蓝色：当前选中；
- 删除项默认隐藏，可通过筛选器重新显示和恢复。

颜色之外必须同时使用线型或状态标记，避免仅依赖颜色表达状态。

### 6.3 编辑行为

- 正点提示模型纳入目标区域；负点排除邻近区域；
- 框选在局部重新生成 mask；
- 多候选输出允许切换后再确认；
- 拆分处理两个岩点粘连，合并处理一个岩点被分成多块；
- 点击空白区域可补加漏检候选；
- 删除误检是可撤销的软删除；
- 所有编辑命令写入追加式日志，并支持撤销和重做；
- 快捷键不得在输入框聚焦时触发。

SVG polygon 仅是 mask 的交互视图。模型修正、拆分和合并必须更新原始 mask，再重新生成 SVG，避免 polygon 多次编辑造成几何退化。

## 7. 评估报告

完成全墙确认后，以最终实例集合为近似真值，为每个模型及合并候选计算：

- 自动候选数量；
- 最终岩点召回率；
- 误检数量与精确率；
- 无需修改、轻微修正、完全重做的实例数量；
- 抽样或全量 mask IoU；
- 补加、删除、重算、拆分、合并次数；
- 模型推理时间、人工编辑时间和总耗时。

候选与最终实例的自动匹配使用 mask IoU，并提供人工修正匹配关系的入口，避免相邻或嵌套对象造成统计错误。

## 8. 错误处理与恢复

- 权重下载失败：展示目标文件、来源、重试操作和校验结果；
- 内存不足：建议或自动降低工作图尺寸、点批量或裁剪并发，创建新实验重试；
- 单模型失败：保留另一分支结果并允许继续人工校正；
- 推理中断：保留已完成的分支和中间产物，实验标记为中断；
- 无候选：保留当前成功结果，展示参数诊断，不以空结果覆盖；
- 浏览器意外关闭：从服务器端实验快照与编辑日志恢复；
- 导出失败：保留编辑状态，输出明确的目标路径与失败原因。

## 9. 测试策略

- 单元测试：mask 清理、IoU、去重、轮廓提取、简化误差、坐标转换；
- 模型适配器契约测试：两个模型输出统一结构，失败返回统一错误；
- 编辑命令测试：正负点、框选、拆分、合并、软删除、撤销和重做；
- API 测试：实验创建、进度、恢复、保存和导出；
- UI 交互测试：SVG 命中、缩放、平移、快捷键和模式切换；
- 真实图回归测试：固定墙图、固定权重与参数下保存候选统计和小尺寸预览快照；
- 人工验收：完成一次整墙校正并生成可解释的双模型报告。

模型输出可能因运行库或硬件而产生小幅差异，真实图回归不比较二进制 mask 的逐字节完全相等；它比较候选数范围、关键实例存在性、几何有效性和报告字段。

## 10. 实现边界

建议实现为本机 Python 服务加浏览器桌面界面：Python 负责模型、mask 和实验持久化；前端负责 SVG 可视化与编辑操作。两者通过小型本地 API 通信，仅监听回环地址。

模型代码、统一后处理、实验存储和 UI 编辑器必须保持独立边界。后续集成 CruxSet 时，只新增经过确认结果到 CruxSet 数据结构的转换器，不把双模型验证逻辑直接塞入现有 Web 编辑器。

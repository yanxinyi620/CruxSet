# 本地实验台账户、归属与发布统一

用户已批准按云端模式统一本地实验台，并明确旧无归属实验归管理员。保留当前工作区已有更新。

浏览器通过 /api/v1/segmentation-lab 请求 FastAPI。FastAPI 复用现有账户、会话，检查管理员或 labEnabled，并对写请求校验同源。8765 保持独立进程、现有分割核心与文件存储，但所有 /api 请求需要可信内部签名。FastAPI 不加载模型。

内部协议：X-CruxSet-Lab-Context 为无填充 base64url 编码 JSON，字段 userId、isAdmin、legacyOwnerId、issuedAt（秒）、method、path（/api/...，不含 query）、bodySha256、query（原始查询串）。X-CruxSet-Lab-Signature 为该编码字符串的 HMAC-SHA256 十六进制值。密钥为 CRUXSET_LAB_INTERNAL_KEY，未设置时兼容现有 CRUXSET_SEGMENTATION_PUBLISH_KEY。验证签名、时间差不超过 60 秒、方法路径查询和正文哈希；不接受浏览器自报身份。

FastAPI 显式返回 capabilities，增加与云端同路径的用户实验台授权管理。每次请求重新读取账户，撤销立即作用于后续 API。授权只包含自己的实验、校准、本地发布，不授予通用墙面管理。

实验归属存独立 owner.json，不修改旧实验正文。新实验创建时记录用户；旧实验仅在无归属时分配到管理员：优先已配置且有效的发布管理员，否则最早创建的管理员（以用户 ID 打破平局）。无管理员时拒绝迁移并报告配置错误。任务与校准继承父实验归属；所有列表、图片、候选、导出、修改、删除与发布均检查归属。管理员没有越过所有者检查的隐含权限。归属初始化幂等，不覆盖既有 owner.json。

本地发布 metadata 中 ownerId 由实验台可信身份生成，FastAPI 发布入口校验该账户当前实验台权限，并限制幂等回执不能跨所有者复用。已有无 ownerId 的机器发布协议保持固定发布身份兼容。普通获授权用户只可发布本地；跨平台发布凭据仍使用各目标配置身份，限管理员操作。

Vite/Caddy 不再将实验 API 直通 8765，统一代理到 8000。独立 8765 页面引导到主站登录入口，不能绕过权限读取数据。保留本地与云端产物隔离，暂保留 Caddy Tunnel 实验路径的现有限制。

验证：授权/撤销/同源/无会话；跨用户列表及深链操作；内部身份伪造和缺钥；旧归属初始化幂等；真实两服务 ASGI 联调与发布身份；前端能力和代理；全套不含真实模型推理的测试、类型检查与两种构建。实际数据迁移前后检查文件数与归属，避免触碰正在运行的实验内容。

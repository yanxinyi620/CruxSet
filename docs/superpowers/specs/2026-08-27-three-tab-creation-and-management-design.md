# CruxSet 三栏重设计、草稿与删除管理设计

**日期：** 2026-08-27  
**状态：** 已确认，待实施

## 目标

重设计小程序底部的“线路 / 创建 / 我的”三栏，使视觉更明亮、有社群感，同时每一栏只承担清晰、互不重复的职责。保留当前 Phase 1 的页面和数据访问分层，不引入新的后端形态。

## 视觉方向

采用方向 C「明亮社群感」，但不做信息流式社交产品。

- 背景使用轻盈的浅色中性色；卡片使用白色和细边框，而非厚重阴影。
- 关键行动和当前状态使用紫色；珊瑚色、薄荷绿只用于轻量提示或状态。
- 收紧大标题，建立稳定的三级文字层级：页面标题、区块标题、卡片标题 / 辅助说明。
- 三个 Tab 使用一致的底部深色导航与选中状态；页面内容留出 TabBar 安全区。
- 不引入没有真实能力支撑的入口、统计或社交指标。

视觉草稿：`.superpowers/brainstorm/1083512-1787829294/content/cruxset-c-layout.html`（仅为本地讨论素材，不提交）。

## 三栏职责

### 线路

首页任务是发现可浏览的墙面，不直接显示路线列表、搜索或随机入口。

1. 列出公开且有可浏览 Layout 的墙面。
2. 选中墙面后，进入墙面页选择 Layout。
3. 只有选中 Layout 后，才进入既有的线路浏览、按编号 / 名称搜索、顺序和随机选择流程。
4. 空状态保持“暂无公开墙面”，不要用创建相关内容干扰浏览路径。

### 创建

这是新内容和未完成创作的唯一入口。

1. **新建墙面**：上传墙面图片、设置私有 / 公开，并创建一个 Draft Layout；创建成功后直接进入首次标注。
2. **我的草稿**：仅列出当前用户拥有的、包含未发布 Draft Layout 的墙面。选择条目进入该 Draft Layout 的标注编辑器，继续标注。
3. **新建线路**：仅展示当前用户拥有的墙面或公开墙面中，存在可定线 Layout 的条目；可定线的条件不变：Layout 已发布、为活动 Layout、且至少有 2 个岩点。
4. 未发布墙面或 Layout 不能在“新建线路”列表出现。

### 我的

这是资源状态与破坏性管理页，不提供编辑或继续标注入口。

1. 显示当前用户创建的墙面及其可见性、Layout 数量和各 Layout 状态。
2. Layout 状态只展示：`草稿，尚未发布` 或 `已发布并锁定`。
3. 不显示“开始标注”“继续标注”“创建新 Layout”之类的编辑动作。
4. 提供删除墙面和删除 Layout 的管理入口；入口必须次于状态信息，避免误触。

## Draft 与发布状态机

```text
新建墙面
  → 自动创建 Draft Layout
  → 首次标注（创建流程）
  → 离开后可在 创建 / 我的草稿 中继续标注
  → 发布 Layout
  → Published + Locked
  → 可以设置线路，不能继续标注
```

- Draft Layout 可多次打开标注编辑器，可继续新增、修改或删除岩点。
- 发布后 Layout 是不可逆锁定状态；不允许更新岩点、再次发布或重新进入标注编辑器。
- 已发布 Layout 的可定线资格仍由 `isRoutableWall` 规则确定，不能仅凭 `published` 字段推断。

## 删除与级联规则

所有删除都是破坏性操作，必须在客户端显示二次确认对话框，明确列出将被删除的内容。

| 操作 | 二次确认后结果 |
| --- | --- |
| 删除 Draft Layout | 删除该 Layout；不存在关联线路。 |
| 删除 Published Layout | 删除该 Layout 以及所有 `wallId + layoutId` 匹配的关联线路。 |
| 删除墙面 | 删除墙面、所有 Layout，以及所有属于该墙面的线路。 |

额外约束：

- 只能删除当前用户拥有的墙面 / Layout。
- 删除失败时保留当前列表，不做乐观移除，并显示可理解的失败提示。
- 删除成功后重新加载“我的”页；若删除当前活动 Layout，相关墙面将不再被创建页的可定线列表选中。
- CloudBase 实现必须在云函数中执行授权和级联，而不是依赖客户端逐条删除；本地 Mock Repository 保持相同语义。

## 非目标

- 不新增真正的社交动态、关注、评论或统计系统。
- 不允许已发布 Layout 重新进入标注。
- 不改变现有墙面 / Layout / Problem 的核心数据模型，也不让页面直接调用 CloudBase API。
- 不在本次重设计中实现 Phase 2 的自动 Polygon 识别。

## 验收标准

1. 三个 Tab 视觉层级、颜色、间距一致；在 375px 宽度上没有横向溢出，底部操作不会被 TabBar 遮挡。
2. 线路 Tab 先显示可浏览墙面；进入墙面并选择 Layout 前，不显示线路检索控制。
3. 创建 Tab 包含新建墙面、我的草稿、新建线路三项；草稿和可定线墙面集合都符合各自资格条件。
4. 我的 Tab 不含标注或创建 Layout 入口，只显示状态与删除管理。
5. Draft Layout 可从“我的草稿”继续标注；发布后不再出现于草稿列表且编辑器拒绝写入。
6. 删除 Published Layout 后，其关联线路同时消失；删除墙面后，其 Layout 与线路同时消失。
7. 非所有者不能通过页面、服务层或云函数删除其他用户资源。
8. Mock 和 CloudBase 两种 Repository 模式都遵循相同行为。

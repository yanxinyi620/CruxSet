# 小程序缓存优化

用户已批准：先缓存后更新、账号隔离本地缓存、图片复用。在原项目实施。

1. 为读取缓存增加可选 stale-while-revalidate：30 秒新鲜期、24 小时硬期限，合并并发；原严格读取保持默认。增加订阅、持久化和容量限制，刷新失败保留旧值，明确不存在/无权限时清除。写入前后失效防止旧请求回填。
2. 浏览专用服务使用上述缓存，登录确认用户后才读取。权限、管理、编辑读取继续严格模式。四个浏览页面订阅后台更新，隐藏/卸载时退订，保持筛选、避免 loading 遮盖已有内容。
3. 图片按用户和文件标识保存到本地，最多 12 张、30 MB、7 天；文件不存在/解码错误/配额不足可下载恢复。保留本地资源路径直接返回行为。
4. 用行为测试验证重启恢复、账号隔离、过期刷新、失败、写入竞争、删除和容量。运行完整测试及类型检查。记录实际验证范围，不将源码验证称为真机验证。

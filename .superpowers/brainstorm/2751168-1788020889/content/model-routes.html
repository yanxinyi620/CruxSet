A · SAM 3 文本 / 示例检测

用文本或框选样例直接寻找同类岩点。自动识别最贴近目标，但 CPU 负担最大，且需实测模型是否理解密集攀岩墙。

优势

  • 能按“岩点”语义筛选
  • 示例框可提高针对性

风险

  • CPU 很慢、内存压力大
  • 模型与环境较新

B · 双模型基准台（推荐）

同一张墙图分别运行 SAM 3 与 SAM 2.1 AMG，统一去重和筛选后并排检查；编辑器复用同一套 SVG 交互。

优势

  • 先用真实墙图选模型
  • 避免过早押注
  • 结果和参数可复现

代价

  • 第一版工作量稍多
  • 需要下载两套权重
密集提示网格→ SAM 2.1→ 筛选 / 去重

C · SAM 2.1 自动 Mask

用密集点网格“分割一切”，再按面积、稳定性、颜色与墙面范围过滤。成熟稳妥，但会产生大量木板、螺丝和阴影候选。

优势

  • 官方自动 Mask 流程成熟
  • 点/框交互修正稳定

风险

  • 不理解“岩点”语义
  • 后处理质量决定召回率

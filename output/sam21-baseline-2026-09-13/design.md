# SAM2.1 单墙参数基线实验

授权：用户要求公开仓库 GitHub Actions 计算，六小时内完成，交付报告与基线。

固定输入：原始 PNG 3837×2737，SHA-256 见 manifest.json。参考为线上墙面 wall_9_PJELYaPR6p 的 369 个轮廓，已验证与本地校准轮廓逐点一致。参考冻结，不因结果调整；这是单张图上的校准基准，不能代替跨墙面验证。

所有推理走已有 segmentation-lab.yml、固定 SAM2.1 Hiera Large 权重以及现有线上后处理；无需修改或部署产品。沿用私有 R2 输入和输出、云端管理员所有权、最多两个并发任务。任务元数据由项目维护凭据创建，随后经标准 runner claim、校验和验证、推理、上传和完成流程。记录 GitHub run、提交版本、参数和完整输出。

先比较整图 48 点与四块重叠 32 点，再比较整图 32/64 和分块48。阈值粗筛 0.75/0.85/0.90 的预测质量与 0.85/0.90/0.95 的稳定度，结果决定局部细调范围。批量固定 8，裁剪层固定 0；优胜者用批量4再验证时间/质量。若耗时超预期缩减网格，保留实测结果，距六小时截止预留30分钟写报告。

主要指标：完整输出多边形在原图像素栅格上 IoU≥0.5 的最大基数一对一匹配 F1；相同匹配数优先 IoU 总和。次要指标 IoU≥0.75 F1、匹配平均 IoU、PQ、误检/漏检、面积三分位召回，以及执行时间。若候选的主 F1 差不超过0.5个百分点，优先严格轮廓匹配质量与较快运行。数量接近369仅作诊断。评估输入为最终可发布多边形，不是模型预测质量分数；不去除不利候选。人工可视化审查漏检/误检；不以参考轮廓作为模型提示。

整图与分块计算量不同，运行时间单列；GitHub整个job耗时含安装缓存，runner耗时含下载、推理及结果打包上传，均不伪称纯推理耗时。仅报告实际完成组别，错误组不算成功。
